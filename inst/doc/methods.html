B-spline Kolmogorov-Arnold Networks in R: method, validation and an application to PLS-SEM latent scores

This vignette documents what splineKANr computes, how the implementation was validated, and how it can be used after a partial least squares structural equation model (PLS-SEM). The recorded results quoted in Sections 3-5 were produced by the scripts listed in system.file("REPRODUCE.md", package = "splineKANr"); the code shown here runs in seconds with the base R backend.

1. Model

A KAN (Liu et al. 2024) with widths \((n_0, \dots, n_L)\) composes layers \(x^{(l+1)}_j = \sum_{i=1}^{n_l} \phi^{(l)}_{ij}\big(x^{(l)}_i\big) + b^{(l)}_j\). Each edge function is

\[ \phi_{ij}(x) = m_{ij}\Big( w^{b}_{ij}\, \mathrm{silu}(x) + w^{s}_{ij} \sum_{m=1}^{G+k} c_{ijm} B_{m,k}(x) \Big), \]

with a mask \(m_{ij} \in \{0, 1\}\), base and spline weights \(w^b, w^s\) and B-splines \(B_{m,k}\) of degree \(k\) on an extended knot vector \(t_1 < \dots < t_{G+2k+1}\) (\(G\) intervals on the domain \([t_{k+1}, t_{G+k+1}]\) plus \(k\) knots on each side, as in pykan). The basis follows the Cox-de Boor recursion on half-open intervals \([t_i, t_{i+1})\),

\[ B_{i,0}(x) = 1\{t_i \le x < t_{i+1}\},\qquad B_{i,p}(x) = \frac{x - t_i}{t_{i+p} - t_i} B_{i,p-1}(x) + \frac{t_{i+p+1} - x}{t_{i+p+1} - t_{i+1}} B_{i+1,p-1}(x), \]

and its derivative is \(B'_{i,p} = \frac{p}{t_{i+p}-t_i}B_{i,p-1} - \frac{p}{t_{i+p+1}-t_{i+1}}B_{i+1,p-1}\). Outside the domain the spline part is, depending on extrapolate, zero ("none", pykan’s behavior), held constant ("clamp") or continued by its first-order Taylor expansion at the boundary ("linear", default), so that the network stays continuous and has non-zero gradients for inputs beyond the training range.

library(splineKANr)
knots <- kan_make_grid(1, grid_size = 5, spline_order = 3)[1, ]
x <- seq(-1, 1, length.out = 201)
B <- kan_bspline_basis_r(x, knots, 3, right_closed = TRUE)
range(rowSums(B))          # partition of unity on the domain
#> [1] 1 1

2. Estimation

kan_fit() minimizes the mean squared error on min-max scaled inputs (mapped to the grid range) and a standardized response, with Adam (either backend) or LBFGS (torch backend). A validation split drives early stopping and the parameters of the best epoch are restored. Grids can be adapted to the data every grid_update_every epochs: the new knots are the blend \(\epsilon\, t^{\text{uniform}} + (1-\epsilon)\, t^{\text{quantile}}\) of the sample (\(\epsilon\) = grid_eps), layer by layer, and the spline coefficients are refitted to the old edge functions by least squares with relative ridge penalty grid_ridge. Optional regularization is pykan’s L1 + entropy penalty on edge activations plus coefficient penalties.

Two backends compute the same model: R torch (autograd, CPU or GPU) and a base R implementation with analytic back-propagation (backend = "r"), which needs no libtorch and serves as the reference for the torch backend.

The B-spline KAN is the most accurate method on the polynomial and the interaction problems and close to the best on the smooth univariate and additive ones, where a GAM, which matches the true structure exactly, is better. It is consistently and clearly more accurate than the Fourier KAN comparator under the same protocol. On Friedman’s ten-input problem the ANN is about twice as accurate and the KAN results vary strongly between seeds (sd 0.35): with one hidden layer of width 3 chosen from the small tuning grid, the KAN is not flexible enough for this target. The KAN is also the slowest method here (base R backend, 3-18 s per fit).

5. Application: predicting satisfaction and loyalty from PLS-SEM scores

A common workflow in marketing and management research estimates a measurement and structural model by PLS-SEM (Hair et al. 2022) and then asks whether the linear structural equations miss non-linear effects. Below, a simulated customer survey (two exogenous constructs with five 10-point items each and a satisfaction construct with three items) is analyzed with the base R PLS-PM routine shipped in inst/applications, and an additive KAN is fitted to the latent scores.

src <- system.file("applications", "pls_pm.R", package = "splineKANr")
source(src)
set.seed(42)
n <- 600
quality <- rnorm(n)
image <- 0.5 * quality + sqrt(0.75) * rnorm(n)
sat <- 0.4 * quality + 0.9 * pmax(image, 0) + rnorm(n, sd = 0.4)
items <- function(lv, k, prefix) {
  z <- sapply(seq_len(k), function(i) 0.8 * scale(lv)[, 1] +
                0.6 * rnorm(length(lv)))
  out <- pmax(pmin(round(5.5 + 1.6 * z), 10), 1)
  colnames(out) <- paste0(prefix, seq_len(k))
  out
}
survey <- data.frame(items(quality, 5, "q"), items(image, 5, "im"),
                     items(sat, 3, "s"))
blocks <- list(Quality = paste0("q", 1:5), Image = paste0("im", 1:5),
               Satisfaction = paste0("s", 1:3))
paths <- rbind(c("Quality", "Satisfaction"), c("Image", "Satisfaction"))
pls <- pls_pm(survey, blocks, paths)
pls_path_table(pls, "pls")
#>      from           to      beta        r2
#> 1 Quality Satisfaction 0.3991555 0.5207929
#> 2   Image Satisfaction 0.4554731 0.5207929
round(rbind(CR = pls$cr, AVE = pls$ave), 3)
#>     Quality Image Satisfaction
#> CR    0.921 0.919        0.893
#> AVE   0.700 0.695        0.735
sc <- pls$scores
train <- seq_len(400)
kfit <- kan_fit(sc[train, c("Quality", "Image")], sc[train, "Satisfaction"],
                hidden = integer(), grid_size = 5, epochs = 300,
                backend = "r", seed = 1)
lfit <- lm(Satisfaction ~ Quality + Image, data = as.data.frame(sc[train, ]))
test <- as.data.frame(sc[-train, ])
rbind(
  kan = kan_metrics(test$Satisfaction,
                    predict(kfit, test[, c("Quality", "Image")],
                            backend = "r")),
  ols = kan_metrics(test$Satisfaction, predict(lfit, test))
)
#>          rmse       mae        r2   n
#> kan 0.6819320 0.5537144 0.5730240 200
#> ols 0.7045009 0.5788747 0.5442943 200
op <- par(mfrow = c(1, 2))
for (v in c("Quality", "Image")) {
  plot(kan_partial_dependence(kfit, sc[train, c("Quality", "Image")], v),
       main = v, ylab = "PD of Satisfaction")
}

par(op)

In this simulation Image raises satisfaction only when it is above average (a kinked effect), which the linear structural model can represent only by a single slope. The partial dependence of the KAN recovers the kink (flat below the mean, rising above it) and the out-of-sample error is somewhat lower than that of OLS. The curve for Quality, whose true effect is linear, bends slightly in the tails where there are few observations; such wiggles should not be over-interpreted. The gain is not automatic: with half the sample size and a milder non-linearity the same comparison favored OLS, because the extra flexibility costs variance. Whether a KAN improves on the structural equations is an empirical question to be settled out of sample, as below. For honest predictive assessment the PLS weights must be estimated on the training rows only; inst/applications/run_application.R does this inside every fold of a repeated cross-validation. In these data the linear structural model predicts as well as or better than every flexible method, and the B-spline KAN performs like a GAM or an ANN. With 250-350 respondents and latent scores that are linear combinations of Likert items, there is no detectable non-linearity that pays for the extra parameters. Here the KAN is useful as a diagnostic: its additive partial-dependence curves give a direct visual check of the linearity assumption of the structural equations, and its cross-validated error shows that relaxing that assumption does not improve prediction. The same pipeline is meant for data where non-linear effects (thresholds, saturation) are expected, or for larger samples.
